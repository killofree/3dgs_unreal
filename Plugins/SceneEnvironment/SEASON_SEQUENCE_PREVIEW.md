# 계절·날씨 테스트 시퀀스

테스트 에셋: `/Game/Mai01_Weather/LS_Mai_AutumnRainWinter_TEST_120s`

기존 Mai_01의 Level Sequence 액터에서 이 에셋을 선택해 재생합니다. 별도 레벨을 사용하지 않습니다. 시퀀스는 원본 Mai_01의 MAI_Weather_Controller와 mai_t_01에 연결되어 있습니다. 3DGS는 기존 렌더링 모드(0)를 사용합니다.

- 0~60초: 기존 폭우·폭포 트랙과 안개
- 64~94초: 겨울색 전환
- 82초부터: 강설 시작
- 90~120초: 적설 높이 0→7cm, 눈 레이어 표시량 증가

겨울 전환·강설·적설 높이·안개 강도 트랙과 컨트롤러 대상 참조/활성화 트랙을 포함합니다. 눈 높이 형상은 사용자가 원본 레벨에서 베이크한 데이터를 사용합니다. 테스트 시퀀스 생성 과정에서는 레벨을 저장하거나 눈을 베이크하지 않습니다.

기존 눈 Niagara에 강설량 전용 입력이 없어 첫 연결에서는 방출량과 낙하 속도가 함께 변합니다. 눈 형상은 기존 베이크 단계 선택이며, 투명도 증가로 최초 표시를 완화합니다. GS 겨울색 전환은 메쉬 단풍 머테리얼까지 바꾸지 않습니다. 실제 화면 품질과 Niagara 임의 시점 탐색의 재현성은 별도 확인이 필요합니다.
